# Keyboard Shortcuts

Everything in Turnover can be done from the keyboard. Every command below is also in the menu bar
(**Tools** and **Element**), so the menus double as the shortcut list.

## Tools (main window)

| Keys | Does |
|---|---|
| Cmd-1 ... Cmd-9 | Open a tool, in sidebar order: 1 Conform Prep, 2 Data Burn-In, 3 Marker, 4 VFX Naming, 5 Auto Marker, 6 VFX Pull EDL, 7 VFX Shot List, 8 VFX Timeline, 9 Title <-> Caption |
| Cmd-[ and Cmd-] | Previous / next tool (wraps around) |
| Cmd-O | Open an FCPXML |
| Cmd-R | Run the tool (Build Burn-In Cache for Data Burn-In) |
| Shift-Cmd-R | Run and send the result to Final Cut Pro |
| Option-Cmd-R | Reveal the result in Finder |
| Option-Cmd-O | Open the result in Final Cut Pro |
| Cmd-K | Customize Data Burn-In... |
| Cmd-E | Export Burn-In Video... |
| Cmd-. | Stop the current export |

A command that cannot be used right now is grayed out in the menu (for example Run before an FCPXML is chosen).

## Moving around with Tab

Tab and Shift-Tab move between buttons, menus and fields, Space presses the focused button, and the arrow
keys change a focused menu or list. macOS only lets Tab reach every control when **Keyboard navigation** is
on: System Settings > Keyboard > Keyboard navigation (or press Control-F7).

## Data Burn-In Customizer

The Customizer is its own window; its keys apply while it is in front. The tool keys of the main window
(Cmd-1 ... Cmd-9, Cmd-R ...) are switched off there so they cannot change the tool behind it.

**Element menu**

| Keys | Does |
|---|---|
| Cmd-N | New element |
| Cmd-D | Duplicate the selected element |
| Option-Cmd-Delete | Delete the selected element |
| Shift-Cmd-A | Deselect: the orange frame leaves the preview (or just click the picture) |
| Shift-Cmd-H | Hide or show the selected element |
| Option-Cmd-Up / Down | Move the element up or down the list |
| Option-Cmd-1 ... 4 | Show the Element, Display, Data or Export settings |
| Shift-Cmd-F | Full screen preview: the preview alone fills the screen (also **F** in the preview) |
| Cmd-Z / Shift-Cmd-Z | Undo / redo |

**Preview and timeline** (not while typing in a text field)

| Keys | Does |
|---|---|
| Space | Play / pause |
| J, K, L | Shuttle back, stop, shuttle forward (press again to go faster) |
| Left / Right (or , and .) | Step one frame |
| Up / Down | Select the previous / next element |
| Option-arrows | Nudge the selected element by one pixel (add Shift for ten) |
| I, O, X | Mark In, mark Out, clear the range |
| F / Esc | Full screen preview on / off (Esc only leaves it) |

## Timeline Index+ (inside Final Cut Pro)

| Keys | Does |
|---|---|
| Cmd-F | Go to the search field (it also searches role names) |
| Down arrow (in the search field) | Go to the list |
| Up / Down | Move through clips; Final Cut's playhead follows |
| Return | Move the playhead to the selected clip again |

Final Cut Pro has its own shortcuts and may use a key before the panel sees it; the keys above are the ones the
panel takes first when it is the active window.
